# NIU Mobility Studio 1.2.9 — статусы команд

Добавлена панель «Результаты команд» в BLE Client. Для последних шести обменов отображаются номер, UUID, отправленный HEX и состояние:

- **ОТПРАВКА** — запись поставлена в очередь/начата.
- **ОТПРАВЛЕНО · ОЖИДАНИЕ ОТВЕТА** — Android GATT подтвердил запись; это не подтверждение выполнения команды ECU.
- **ОТВЕТ ПОЛУЧЕН · ACK НЕ ПРОВЕРЕН** — после отправки пришёл пакет NOTIFY/INDICATE/READ. Пакет считается кандидатом ответа по времени, пока формат протокола не декодирован.
- **ОШИБКА ОТПРАВКИ** — GATT вернул ошибку.
- **ОШИБКА · НЕТ ОТВЕТА** — в течение 5 секунд после записи не поступил входящий пакет.
- **ПРЕРВАНО** — начат следующий обмен до завершения предыдущего.

Важно: пока нет документированного формата ACK NIU для точной модели/прошивки, приложение не показывает «Команда выполнена успешно» только на основании GATT_SUCCESS или произвольного входящего пакета. Это предотвращает ложные положительные результаты.

Версия и versionCode не изменены: 1.2.9 / 129.
