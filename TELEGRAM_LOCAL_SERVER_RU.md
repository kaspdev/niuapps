# Telegram и локальный API — 1.0.8

## Telegram Bot API

1. Создайте бота через официальный `@BotFather` и скопируйте токен.
2. Откройте **Инструменты → Telegram и локальный сервер**.
3. Задайте имя профиля (можно хранить несколько профилей), вставьте токен и укажите разрешённые Chat ID через запятую.
4. Сохраните/проверьте токен. По желанию установите команды `/start`, `/help`, `/status`.
5. Убедитесь, что на боте не настроен Webhook: приложение проверяет его наличие и не удаляет автоматически. Запустите Long Polling. Одновременно активен один профиль бота; сохранённых профилей может быть несколько.

Токены хранятся в `SecureSecretStore` (AES-GCM, ключ Android Keystore). Токены не записываются в журналы. Бот отклоняет сообщения от chat ID вне allowlist. Не публикуйте токен и не отправляйте его в диагностические отчёты. При компрометации отзовите его через BotFather.

### Команды

- `/start` и `/help` — краткая справка.
- `/status` — состояние интеграции и ограничение доступности данных скутера.

На этом этапе бот не выдаёт телеметрию скутера, не управляет ECU и не запускает команды блокировки/разблокировки. Это будет добавляться только для подтверждённых моделей, протоколов и прав владельца.

## Локальный HTTP API

По умолчанию сервер слушает только `127.0.0.1`. Включение LAN bind на `0.0.0.0` — отдельное действие в UI. Требуется Bearer key длиной минимум 24 символа; ключ хранится в Android Keystore.

- `GET /health` — состояние API.
- `POST /notify` — принимает JSON `{"message":"текст уведомления"}` и, если выбранный бот и список chat ID настроены, пересылает сообщение в Telegram.

Пример запроса:

```bash
curl -H 'Authorization: Bearer YOUR_LOCAL_API_KEY' \
  http://127.0.0.1:8765/health

curl -X POST -H 'Authorization: Bearer YOUR_LOCAL_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"message":"NIU Mobility Studio: тестовое уведомление"}' \
  http://127.0.0.1:8765/notify
```

Сервер работает в процессе приложения и останавливается при закрытии процесса/Activity. Это не системный демон и не гарантированный 24/7 сервер. Для работы извне домашней сети нужен отдельный защищённый сервер/VPN/reverse proxy. Telegram Webhook требует публичного HTTPS endpoint и в этой версии не включён. Не пробрасывайте порт обычного HTTP API в интернет: LAN режим предназначен только для доверенной локальной сети, где возможен перехват незашифрованного HTTP.

## Ограничения и проверка

- Интеграция использует официальный HTTPS Bot API Telegram.
- Long Polling выполняется в отдельном daemon thread, без фонового Android foreground service; ОС может остановить процесс в фоне.
- Один бот активен одновременно; профили токенов могут храниться отдельно.
- Telegram-команды пока базовые; интеграция со скутером и push-уведомлениями из NIU Cloud не заявляется как реализованная.
- Локальный API принимает только `/health` и `/notify`; все запросы требуют Bearer authentication.
