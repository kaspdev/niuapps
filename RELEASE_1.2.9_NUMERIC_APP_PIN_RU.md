# NIU Mobility Studio 1.2.9 — Numeric App PIN

- При первом запуске показывается мастер установки PIN-кода приложения.
- PIN состоит только из цифр, длина 4–8 знаков; ввод ограничен цифровой клавиатурой.
- PIN запрашивается повторно для подтверждения.
- PIN хранится как PBKDF2-HMAC-SHA256 verifier с индивидуальной случайной 16-байтовой солью (180 000 итераций); исходный PIN не сохраняется.
- По желанию при настройке включается Android BiometricPrompt с `BIOMETRIC_STRONG`.
- При последующих запусках доступен вход по PIN или отпечатку (если биометрия была включена и доступна).
- Биометрические шаблоны приложение не читает и не хранит.
- Отдельный ранее существовавший пароль защищённого меню инструментов не изменён.
- Версия сохранена: versionName 1.2.9, versionCode 129.

Проверка ZIP: `unzip -t`.
Android-компиляция не выполнялась в этой среде; требуется Gradle Sync и сборка в Android IDE.
