# NIU Mobility Studio 1.1.9 — FK OAuth login

## Исправления NIU Cloud

- Убран устаревший `appv2/login` из основного пути авторизации.
- Добавлен NIU OAuth v3: `account`, `app_id`, `grant_type=password`, MD5-хеш пароля и `scope=base`.
- Добавлена обработка OAuth-ответа `data.token.access_token` и совместимых вариантов.
- GET-запрос не отправляет пустое тело формы; query string не выводится в логи.
- MD5 считается на устройстве из `CharArray`; временный byte array очищается.
- Ошибка загрузки списка транспорта отделена от ошибки входа. Если токен получен, он сохраняется даже при сбое списка.
- Удалено поле countryCode: оно относилось к старому appv2 phone-login контракту, а не к OAuth v3.
- Версия приложения: `1.1.9`, `versionCode=119`.

## Проверка и ограничения

FK OAuth endpoint и структура токена сверены с публичной реализацией NIU для evcc. В этой среде нет Android SDK/Gradle Wrapper, поэтому APK здесь не собран и живой вход в NIU не проверен. Нужна проверка на устройстве. В частности, NIU может дополнительно требовать актуальные параметры/подпись клиента; в таком случае диагностический журнал покажет HTTP-код и форму JSON-ответа без записи пароля или токена.

Это не официальный SDK NIU. Глобальный OAuth host использует аналогичный путь, но в этой сборке отдельно не подтверждён живым GLOBAL-аккаунтом.
