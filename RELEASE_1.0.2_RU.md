# NIU Mobility Studio 1.0.2

## Обновление

- Экран скутера переработан под scooter-first интерфейс: статус BLE, карточка устройства, быстрые действия, метрики и диагностика. Неизмеренные скорость/заряд/пробег отображаются как `—`, а не выдуманными значениями.
- Добавлен реестр проверок команд с модельной привязкой, доказательностью, штатной авторизацией и проверкой неподвижности для операций управления.
- LOCK/UNLOCK, звуковой сигнал, режим езды и сигнализация остаются заблокированными, пока точный протокол не подтверждён для NIU FX Wind Strike.
- AI подключается честно: вход в ChatGPT открывается на стороне провайдера; исходник передаётся только по явному действию пользователя. Это не универсальный OAuth/API grant.
- GitHub Device Flow запускается кнопкой. Публичный Client ID OAuth App настраивается один раз; секреты пользователя не запрашиваются вручную.

## Проверка

Исходный ZIP был целостен до изменения. В этой среде отсутствует Gradle и Android SDK, поэтому полная Android/Compose компиляция и APK assembly не подтверждены. До релиза требуется зелёный GitHub Actions build и тест на реальном NIU FX Wind Strike.
