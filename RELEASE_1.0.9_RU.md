# NIU Mobility Studio 1.0.9 — Telegram AI Bridge

- Исправлены две ошибки `Unsupported escape sequence` в экспорте JSON/CSV логов: регулярное выражение переведено на Kotlin raw string.
- Telegram bot теперь предоставляет `/logs`, `/errors`, `/analyze`, `/ai` и `/fix`.
- Добавлен AI чат через настраиваемый HTTPS backend. Контракт описан в `TELEGRAM_AI_BRIDGE_RU.md`.
- Добавлен опциональный автоматический анализ критических ошибок с уведомлением разрешённых Telegram Chat ID (не чаще одного анализа в минуту).
- API-токен backend хранится в Android Keystore; секреты не включаются в контекст.
- AI получает только маскированные и ограниченные диагностические строки.
- `/fix` только просит план исправления; автоматическое изменение исходников не выполняется.
- Версия приложения: 1.0.9 (versionCode 109).

Проверки в этой среде: ZIP integrity, XML parse, JSON/YAML parse и статическая проверка исходников. Полная Android/Compose Gradle-сборка и реальные сетевые интеграционные тесты не подтверждены.
