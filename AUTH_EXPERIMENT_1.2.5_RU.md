# Эксперимент авторизации NIU Mobility Studio 1.2.5

## Что изменено
- Сохранён основной OAuth v3 GET-запрос и существующий App ID `niu_8xt1afu6`.
- Добавлен диагностический повтор POST с `application/x-www-form-urlencoded` только если GET получает серверное сообщение `App version is too outdated`.
- POST использует те же параметры OAuth и тот же App ID; приложение не выдаёт себя за официальный клиент.
- Добавлено безопасное логирование факта повторной попытки и результата обоих вариантов.
- Сохранены `versionName=1.2.5` и `versionCode=125`.

## Что намеренно НЕ менялось
- Не подставлялся альтернативный App ID: его актуальность для NIU Cloud не подтверждена исходным кодом проверенного проекта.
- Не добавлялся выдуманный refresh-token endpoint. Refresh token будет сохраняться/обновляться только после подтверждения реального контракта NIU.
- Не менялся API списка скутеров `/motoinfo/list`: найденные публичные материалы не подтвердили совместимость v5 для этого профиля авторизации.

## Проверка
Это диагностический эксперимент, а не гарантированное исправление. Необходимо установить APK и выполнить по одной попытке входа для GLOBAL и CHINA, затем сравнить записи:
- `profile=legacy-get`
- `profile=post-form`
- `EXPERIMENTAL_RETRY_FAILED` либо `TOKEN_RECEIVED`

Если оба варианта возвращают `outdated`, причина вероятнее всего связана с политикой клиента/App ID/подписью на стороне NIU, а не с GET против POST.
