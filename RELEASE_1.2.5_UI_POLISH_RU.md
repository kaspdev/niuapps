# NIU Mobility Studio 1.2.5 — интерфейс, справка и загрузка

## Добавлено
- Векторный логотип NIU Mobility Studio: используется в стартовом экране, верхней панели, главном экране, разделе «О приложении» и как иконка приложения Android.
- Анимированный экран запуска: пульсация логотипа, вращающееся кольцо акцента, индикатор загрузки и номер версии. После короткой заставки открывается последний выбранный раздел.
- Контекстные кнопки информации для основных действий BLE/GATT, журнала, mdpaste, диагностики, музыки, звуков, Workspace, GitHub Build Center и управления транспортом.
- Дополнены описания разделов и распространённых действий. Особо отмечено, где операция работает только локально и где команды скутера пока не подтверждены.
- Сохранён экспорт журнала в TXT, MD, JSON, CSV и ручная подготовка Markdown для mdpaste.ru.

## Поведение mdpaste.ru
Приложение очищает распознаваемые секреты в журнале, копирует Markdown в буфер обмена и открывает `https://mdpaste.ru/`. Пользователь вставляет текст и публикует его самостоятельно. Документированный API создания публикаций не подтверждён, поэтому приложение не заявляет об автоматической отправке.

## Проверки и ограничения
- XML разметка логотипа и AndroidManifest проверена на корректность.
- Kotlin-файл проверен компилятором на синтаксические ошибки; без Android/Compose classpath компиляция файла отдельно закономерно выдаёт unresolved references.
- Полная сборка APK не выполнялась: в рабочем окружении нет Android SDK и Gradle wrapper/toolchain. Не считать архив установленным или проверенным APK.
- Маскирование журнала основано на распознаваемых форматах секретов и не гарантирует удаление любых произвольных персональных данных. Перед публикацией просмотрите текст.
