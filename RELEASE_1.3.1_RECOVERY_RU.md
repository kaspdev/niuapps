# NIU Mobility Studio 1.3.1 — восстановление и доработка

Основа: исходный архив 1.3.0 UI Simplified.

## Включено
- Экспорт установленного APK вынесен в отдельный пункт защищённых инструментов. В Build Center оставлены операции сборки/скачивания/установки APK.
- Журнал: добавлены переключатели временного/постоянного хранения и автопрокрутки; список использует отдельное состояние прокрутки. Временный режим оставляет новые события только в памяти приложения.
- Список скутеров упрощён до компактного селектора; детали и контекстные действия показываются для выбранного профиля.
- В первоначальном архиве была добавлена облачная отправка логов; по последующему решению она удалена в текущем восстановительном проходе. Локальное логирование сохранено.

## Последующие изменения восстановления
- Добавлены Gradle-варианты `full` и `user`: в пользовательском варианте защищённые инструменты отключены флагом сборки, но их исходный код остаётся в приложении. Экран журнала остаётся доступен.
- CI собирает оба debug-варианта.
- Отдельное административное приложение и безопасное подписание/проверка разрешений для повторной активации защищённых функций ещё не реализованы; один лишь локальный флаг сборки не считается административной авторизацией.

## Ограничения
- Прямой OAuth для Google Drive, Dropbox и OneDrive не реализован: эти провайдеры могут быть подключены через собственный HTTPS bridge/webhook.
- MQTT нативный клиент пока не добавлен.
- APK export может включать только base APK на устройствах с split APK.
- Компиляция не подтверждена: в исходном архиве отсутствует Gradle Wrapper; наличие установленного Gradle проверяется отдельно.
