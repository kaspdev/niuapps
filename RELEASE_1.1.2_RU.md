# NIU Mobility Studio 1.1.2

## Telegram: команды, меню и консоль

### Команды бота
- `/start`, `/help` — справка;
- `/menu` — отправить настроенное inline-меню;
- `/status` — состояние интеграции, BLE и NIU Cloud;
- `/vehicle` — активный профиль транспорта;
- `/models` — семейства NIU в каталоге;
- `/ble` — состояние и подсказка BLE;
- `/cloud` — состояние NIU Cloud;
- `/service` — сведения о журнале обслуживания;
- `/logs`, `/errors` — последние события и ошибки;
- `/analyze`, `/ai`, `/fix` — AI-анализ, вопрос и предложение исправления (требуется HTTPS backend; исправления автоматически не применяются);
- `/ping`, `/version` — проверка связи и версия.

Команды автоматически регистрируются через `setMyCommands` при старте Long Polling и доступны также через кнопку ручной установки.

### Редактор кнопок
В разделе Telegram добавлен редактор inline-кнопок. Каждая строка имеет формат `Подпись|/команда`. Допустимые команды проверяются перед отправкой; максимум 12 кнопок в меню. Можно сохранить конфигурацию локально и отправить меню всем разрешённым Chat ID. Нажатия обрабатываются через Telegram `callback_query` и проходят ту же проверку allowlist.

### Консоль
Живая консоль отображает Bot API запросы и HTTP-статусы, время ответа, входящие сообщения и callback-кнопки, команды, ошибки DNS/CONNECT/TIMEOUT и интервалы повторного подключения. Есть фильтры «Все», «Ошибки», «API», «Команды» и экспорт TXT. Полный токен и URL с токеном не записываются.

### Сеть и безопасность
Long Polling использует повторные попытки с увеличивающейся задержкой до 30 секунд. Сетевые проблемы не удаляют сохранённый токен. Webhook не отключается автоматически, поскольку может использоваться другой интеграцией. Для запуска требуется хотя бы один разрешённый Chat ID.

## Проверка
Статическая проверка структуры и Kotlin-синтаксиса выполнена. Полная Android Gradle-сборка и реальный запрос к Telegram API не выполнены в этой среде: архив не содержит Gradle Wrapper, а Android SDK/Gradle toolchain недоступны. Для подтверждения работы нужно собрать APK и проверить сеть на устройстве.

## Дополнительные исправления по журналу 1.1.1

- BLE: перед новым scan-сеансом останавливается предыдущий callback-сеанс; ошибка Android scan code 1 и другие стандартные коды теперь расшифровываются в журнале.
- QR: журнал указывает класс/причину ошибки Google code scanner и предлагает ручной ввод SN, если модуль сканирования недоступен.
- NIU Cloud: сообщение `App version is too outdated` распознаётся как отказ версии клиента на стороне сервера; интерфейс объясняет, что повторный ввод пароля не решает это ограничение. Клиентский User-Agent обновлён до версии проекта 1.1.2, но серверную совместимость это не гарантирует.
