# NIU Mobility Studio 1.2.5 — подготовка журнала для mdpaste.ru

## Что добавлено
- В разделе «События и ошибки» добавлена команда «Скопировать и открыть mdpaste.ru».
- Перед копированием приложение показывает предупреждение о внешней публикации и просит подтверждение.
- Формируется Markdown-отчёт с версией приложения, Android SDK и последними 500 событиями.
- Отчёт ограничен 512 КиБ.
- Перед помещением в буфер обмена повторно маскируются пароли, токены, заголовки Authorization, cookie, API keys, e-mail, account/phone, VIN/SN и Bluetooth MAC-адреса.
- После копирования открывается `https://mdpaste.ru/`; пользователь вставляет текст в поле сайта и самостоятельно подтверждает публикацию.
- Существующий экспорт в TXT, MD, JSON и CSV остаётся без изменений.

## Важное ограничение
Автоматическая отправка через API не реализована: на момент подготовки не удалось подтвердить документированный API mdpaste.ru и формат его ответа. Приложение не делает недокументированный HTTP-запрос и не утверждает, что заметка уже опубликована. После ручной публикации пользователь копирует полученную ссылку с сайта.

## Приватность
mdpaste.ru является внешним сайтом. Настройки приватности и срок хранения созданной заметки приложению неизвестны. Считайте вставленный текст потенциально публичным; предупреждение показывается перед копированием. Маскирование основано на известных форматах секретов и не гарантирует распознавание произвольных пользовательских данных — перед публикацией нужно проверить текст.

## Сборка и тесты
- Добавлен `DiagnosticLogRedactorTest` для маскирования credential-полей, Bearer, JWT, e-mail и MAC-адреса.
- Версия приложения остаётся `1.2.5`, `versionCode = 125`.
- Полная Android-сборка требует Android SDK и Gradle toolchain; в среде подготовки архива они отсутствуют, поэтому APK не заявляется как собранный.
