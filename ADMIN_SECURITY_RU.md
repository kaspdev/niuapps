# Административная защита NIU Mobility Studio

## Реализовано в исходниках

- Административная консоль встроена в Full-вариант основного приложения (`app/src/full`); отдельного Admin APK и отдельного Android-модуля больше нет.
- Администратор создаёт пару ECDSA P-256 в Android Keystore; приватный ключ не экспортируется.
- Admin выдаёт подписанное разрешение формата `base64url(payload).base64url(signature)`.
- Разрешение ограничено конкретным Installation ID пользовательской установки, содержит срок действия (1–365 дней), перечень разрешённых функций и уникальный ID.
- User APK проверяет подпись `SHA256withECDSA`, закреплённый открытый ключ, идентификатор установки и срок действия до показа защищённых инструментов.
- Без разрешения защищённые маршруты пользовательской сборки закрыты. Full flavor сохраняет локальную защиту паролем.
- В release включены R8 и shrinkResources. Ключ администратора не хранится в приложении; в User APK попадает только открытый ключ.

## Обязательная процедура первого развёртывания

1. Соберите и установите Full APK (`:app:assembleFullDebug`). Административная консоль открывается из раздела Build Center → «АДМИНИСТРИРОВАНИЕ · КЛЮЧИ · ДОСТУПЫ».
2. В Admin нажмите «Создать / проверить ключ администратора». Сохраните отображённый открытый ключ в защищённом хранилище проекта. Не удаляйте данные Admin и не переустанавливайте его: приватный ключ создан в Android Keystore и не восстанавливается из APK.
3. Перед сборкой User задайте Gradle property `NIU_ADMIN_PUBLIC_KEY` равным Base64 открытого ключа:
   `gradle -PNIU_ADMIN_PUBLIC_KEY='<BASE64>' :app:assembleUserRelease`
   Для CI задайте GitHub Actions Variable `NIU_ADMIN_PUBLIC_KEY`.
4. Установите собранный User APK. В разделе защищённых инструментов скопируйте Installation ID.
5. В Admin вставьте Installation ID, задайте срок и подпишите разрешение. Передайте токен на пользовательское устройство.
6. В User вставьте токен и нажмите проверку. После успешной проверки доступ будет открыт; локальный пароль защищённых инструментов остаётся дополнительным барьером.

## Важные ограничения модели

- Изменение открытого ключа означает новую доверенную сборку User APK. Публичный ключ нельзя произвольно заменить внутри уже установленного приложения.
- Выданный офлайн-токен действует до указанного срока. Мгновенный отзыв без связи с сервером невозможен; для досрочного прекращения доступа очистите данные приложения/отзовите локальный grant на устройстве. Для централизованного отзыва нужен онлайн-сервис проверки или регулярно обновляемый подписанный denylist.
- Удаление/переустановка Admin уничтожает доступ к приватному ключу. Для ротации ключей создайте новый ключ и выпустите новую User-сборку с новым публичным ключом.
- Подпись разрешения управляет доступом к функциям приложения, но не является защитой от владельца устройства с root/отладчиком, модифицированной ОС или перепакованного APK. Критические операции ECU всё равно должны требовать проверок безопасности и подтверждения пользователя.
- APK генерируется Gradle/CI, а не самокопированием установленного APK. Существующий экран Export APK передаёт текущую установленную сборку.

## Проверка сборки

`./BUILD_ALL.sh` требует JDK 17, Gradle 8.9+ и Android SDK 35. Он собирает Full и User debug APK, а также запускает доступные JVM-тесты. Административная консоль включена в Full APK; User flavor не содержит кода консоли. Release-подпись требует отдельного keystore. В текущей среде компилятор Android SDK/Gradle не установлен, поэтому APK и успешный compile здесь не заявляются.

## Дополнение к 1.3.1 ADMIN PROTECTED

- В административном приложении добавлен PIN администратора: при первом выпуске/отзыве задаётся PIN длиной от 8 символов; для каждой операции требуется повторное подтверждение. Хранится только PBKDF2-HMAC-SHA256 verifier с индивидуальной случайной солью (210 000 итераций). PIN не записывается в журнал.
- Добавлен подписанный офлайн-список отзыва `NIU-REVOKE-1`. В Admin укажите UUID выданного разрешения (показывается после выпуска), подтвердите PIN и передайте список на пользовательское устройство.
- В User импорт списка отзыва проверяет ECDSA подпись тем же закреплённым публичным ключом, объединяет список без удаления ранее отозванных ID и удаляет текущий grant, если его ID отозван. Импортировать обновлённый список можно и из хаба защищённых инструментов через «АДМИН-ДОСТУП».
- Отзыв офлайн-токена не может быть мгновенным без канала связи: он вступает в силу на конкретном устройстве после доставки/импорта списка отзыва. Для централизованного онлайн-отзыва нужен отдельный сервер, который в текущем объёме намеренно не добавляется.
- Build Center предлагает только два артефакта: `niu-full-debug-apk` и `niu-user-debug-apk`. Административная консоль находится внутри Full APK; отдельный Admin APK не выпускается.

## Ограничения безопасности

PIN в Admin — локальный барьер от случайного доступа, а не аппаратная биометрическая аттестация. Подписывающий закрытый ключ остаётся в Android Keystore. На root/jailbreak-устройстве или при модифицированной ОС гарантировать защиту локального приложения невозможно. Офлайн-отзыв не доставляется автоматически по BLE: список передаётся пользователем через системный Share/копирование и импортируется в User. Разрешение привязано к Installation ID приложения, а не к серийному номеру скутера.
