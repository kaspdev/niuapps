# NIU Mobility Studio 1.1.5

## Классическая авторизация NIU Cloud

- Удалён экран ручного ввода NIU session token и кнопка подключения через внешний токен.
- Основной и единственный пользовательский сценарий входа — Email/логин + пароль, с выбором региона GLOBAL / CHINA.
- Для Email поле кода страны не показывается и параметр `countryCode` не отправляется; для телефонного логина поле остаётся доступным.
- Сессионный ключ, возвращённый самим NIU после успешной парольной авторизации, используется только внутри приложения и хранится в Android Keystore для последующих запросов API. Это внутренняя часть классической авторизации, не отдельный способ входа.
- HTTP error body теперь разбирается до формирования ошибки: серверные `desc` / `message` доступны для диагностики даже при HTTP 4xx/5xx.
- Исправлена классификация ответа `App version is too outdated`: он не отображается как неверный пароль.
- User-Agent приложения обновлён до версии 1.1.5; не используется подмена идентичности официального NIU app.

## Ограничения совместимости

Публично доступная схема password-login устарела (историческая reverse-engineered спецификация 2019 года). Если сервер NIU продолжает требовать новые обязательные параметры/подпись/версию официального клиента, клиент не может достоверно угадать их. В этом случае приложение покажет ответ сервера, а не будет маскировать отказ фиктивной успешной авторизацией. Для полного восстановления входа потребуется актуальный контракт NIU либо захват обезличенных запросов официального приложения с согласия владельца аккаунта.

## Проверки

- Статически проверены отсутствие ручного token-input UI и вызова token-fallback.
- Проверена корректность XML-манифеста и целостность ZIP.
- Полная Android-сборка и live-login с NIU Cloud не подтверждены в текущей среде.
