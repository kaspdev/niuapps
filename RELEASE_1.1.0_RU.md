# NIU Mobility Studio 1.1.0

## Документация в приложении
- Новый экран «Документация / README» доступен из «Инструменты».
- Просмотр встроенного полного README без ручного импорта.
- Экспорт README через Android Storage Access Framework: Markdown (`.md`), plain text (`.txt`), HTML (`.html`) и JSON (`.json`).
- Добавлен отдельный экспорт краткого паспорта проекта для AI-агентов.

## Для AI-агентов
- `AI_AGENT_BRIEF.md` — краткое назначение, стек, структура каталогов, ограничения и правила безопасной работы.
- `AGENTS.md` — инструкции агентам, работающим с репозиторием.
