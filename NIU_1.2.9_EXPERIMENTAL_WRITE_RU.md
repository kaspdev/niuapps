# NIU Mobility Studio 1.2.9 — Experimental GATT Write

- Разрешена ручная отправка пользовательских HEX-пакетов в наблюдавшиеся NIU candidate характеристики `8ec94e32` и `99ea30e2`, если сама характеристика объявляет WRITE или WRITE WITHOUT RESPONSE.
- `8ec94e33` остаётся закрытым: ранее зафиксирован GATT AUTH FAIL (0x89), это защищённый канал.
- В журнал добавляется явная отметка экспериментальной отправки и `ECU_ACK_NOT_CONFIRMED`.
- GATT_SUCCESS означает только успешное завершение операции записи на уровне BLE, а не выполнение команды ECU.
- Автоматические LOCK/UNLOCK/FIND/MODE payload не добавлялись: достоверные байты и handshake для точной модели/прошивки отсутствуют. Команды не разблокируются выдуманными пакетами.
- Перед экспериментом скутер должен быть неподвижен; использовать только пакеты из собственного захвата штатного приложения.

## Дополнение: BLE Exchange Engine (тот же номер 1.2.9)
Добавлены нумерация TX/RX-обменов, HEX-журнал, окно ожидания RX 5 секунд, фиксация RX-кандидатов, автоматическая подписка на Chip→App Notify перед ручной записью в известные кандидатные каналы (если доступна), а также REPEAT LAST. Это не раскрывает неизвестные payload LOCK/UNLOCK/FIND/MODE и не считает GATT_SUCCESS подтверждением ECU. Подробности: `NIU_1.2.9_BLE_EXCHANGE_ENGINE_RU.md`.
