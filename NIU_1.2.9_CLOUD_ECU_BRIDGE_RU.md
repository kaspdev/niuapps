# NIU Mobility Studio 1.2.9 — Cloud ↔ ECU bridge

## Что добавлено
- В панели управления появился блок `NIU CLOUD ↔ ECU`.
- Используется существующая NIU Cloud-сессия, хранящаяся через `SecureSecretStore`.
- Ручная синхронизация повторно вызывает существующий `motoinfo/list` через `NiuCloudClient`.
- Облачная запись сопоставляется с выбранным локальным/BLE-профилем только по точному серийному номеру (SN).
- Показываются имя, модель и VIN из облачной записи; при расхождении модели выводится предупреждение.
- Инфоподсказка объясняет границы: Cloud-link подтверждает запись аккаунта, но не BLE/ECU и не является каналом управления.

## Безопасность и ограничения
- Не добавлялись неизвестные Cloud endpoints и управляющие запросы.
- Пароль не сохраняется; токен остаётся в существующем зашифрованном хранилище.
- Никакие lock/unlock/find/ride-mode команды через Cloud не отправляются.
- Точный SN match — единственный критерий связи локального профиля с Cloud-записью; модельное расхождение отображается как предупреждение.
- Версия сохранена: `versionName=1.2.9`, `versionCode=129`.
