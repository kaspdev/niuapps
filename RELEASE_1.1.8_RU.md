# NIU Mobility Studio 1.1.8 — FK login compatibility update

## Изменения
- Профиль FK (`account-fk.niu.com` + `app-api-fk.niu.com`) выбран по умолчанию для новых установок, поскольку пользователь подтвердил успешный вход официального NIU app через эти хосты.
- В интерфейсе профиль подписан `FK · NIU app`; ранее сохранённый выбор региона не перезаписывается.
- При входе по email параметр `countryCode` теперь не отправляется. Он отправляется только для логина/телефона, где он применим. Это устраняет неоднозначность, когда телефонный код передавался вместе с email.
- Улучшена обработка числового и строкового поля `status` в ответе API.
- Сохранены классическая авторизация email/логин + пароль и безопасное хранение session token.
- Версия приложения: `1.1.8`, versionCode `118`.

## Что подтверждено сетевым захватом
Официальное приложение NIU успешно авторизовалось и показало транспорт при соединениях с `account-fk.niu.com`, `app-api-fk.niu.com`, `app-socket-fk.niu.com` и `ncsi-fk.niu.com`. PCAPdroid CSV не раскрывает HTTP-пути, заголовки и тела HTTPS-запросов.

## Ограничения
OAuth v3 endpoint и его параметры не добавлены: в доступных материалах нет подтверждённого актуального контракта для этого потока. Текущий клиент продолжает использовать опубликованный legacy appv2 контракт (`/appv2/login` и `/motoinfo/list`). Это обновление исправляет передачу countryCode для email и выбор FK-региона, но не гарантирует, что NIU не отклонит старый контракт как устаревший.
