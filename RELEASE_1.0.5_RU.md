# NIU Mobility Studio 1.0.5 — Unified Diagnostics

## Журнал событий
- Расширен единый журнал действий приложения: до 1500 последних записей, локальное сохранение между запусками.
- Добавлены фильтры «Все», «Ошибки», «BLE», «NIU Cloud» и счётчики Cloud/ошибок.
- Экспорт TXT, Markdown, JSON и CSV использует общий журнал.
- В журнал добавляется событие старта приложения; предыдущие аварийные отчёты сохраняются и поднимаются при следующем запуске.
- Добавлена централизованная маскировка токенов, паролей, cookies и Bearer credentials перед сохранением.

## NIU Cloud trace
- Логируются начало/результат входа, регион, маскированный аккаунт, запросы/ответы HTTP, endpoint без query string, HTTP-код, длительность, размер ответа, наличие token header, ключи form-полей, API status, ошибки сети/HTTP/JSON и количество полученных устройств.
- Опциональный режим «Расширенная диагностика ответов» записывает структуру JSON: пути полей, типы и размеры массивов без значений персональных полей.
- Пароль, session token, refresh token и сырые заголовки авторизации не записываются. SN в Cloud trace маскируются.
- Никакие сырые тела запросов или ответов не экспортируются.

## Ограничения
- Это диагностическое логирование клиента, а не MITM/перехват системного сетевого трафика других приложений.
- Журнал ограничен 1500 событиями для контроля размера SharedPreferences. Экспортируйте отчёт после диагностической сессии.
- Полная Android/Compose-сборка должна быть выполнена в окружении с Android SDK и Gradle.
