# NIU Mobility Studio 1.2.5

## Исправления по диагностике 1.2.4

### BLE
- Добавлена одна контролируемая повторная попытка при `SCAN_FAILED_ALREADY_STARTED`.
- Перед повтором приложение явно останавливает предыдущий callback и ждёт 700 мс.
- Повтор не запускается бесконечно и не применяется к ошибкам разрешений, неподдерживаемого BLE или исчерпания ресурсов.
- В журнал добавляются состояние Bluetooth, факт использования повтора и причина отмены.

### Telegram
- Диагностика Long Polling теперь классифицирует DNS, timeout, connect и Telegram API ошибки.
- Учитывается `parameters.retry_after` от Telegram при HTTP 429; задержка ограничена 1–120 секундами.
- Сохранена экспоненциальная задержка для временных сетевых ошибок.
- Токен бота и URL с токеном не записываются.

### NIU Cloud
- Обновлена строка User-Agent до версии приложения 1.2.5.
- Диагностика явно указывает, что при ответе `App version is too outdated` проверка учётных данных не подтверждена и алгоритм приватной подписи не реализован.
- Протокол авторизации намеренно не дополнен неподтверждёнными заголовками или выдуманной подписью.

## Ограничения проверки

ZIP проверен на целостность и исходники проверены статически. Android-сборка и реальное подключение к устройствам/сервисам в этой среде не выполнялись. Ответ NIU `status=400` с сообщением об устаревшем клиенте остаётся нерешённым ограничением серверной совместимости.
