# NIU Mobility Studio 1.0.7

## Обновление универсальной платформы
- Единое название NIU Mobility Studio во всём основном интерфейсе и документации.
- Сохранён прежний `applicationId` `com.niu.fxstudio`, чтобы обновление могло устанавливаться поверх предыдущей версии без потери локальных данных. Внутренний Kotlin namespace также оставлен совместимым.
- Главная карточка теперь отражает выбранную линейку и модель, а не всегда показывает FX.
- Каталог расширен вариантами NQiX/NQi Cargo, MQiL, UQi Cargo, GOVA C0/F2, FX 150/300, RQi Pro, FQi Air/100 и KQi 200.
- Добавлен локальный раздел «Поездки и обслуживание»: показания одометра, целевой пробег следующего обслуживания, заметки, чек-лист владельца, история работ и поездок, расчёт дистанции по введённым данным и экспорт отчёта.
- Журнал обслуживания хранится локально отдельно для каждого активного SN-профиля; он не выдаёт пользовательские отметки за телеметрию ECU.
- AI diagnostic handoff использует выбранный профиль модели вместо жёсткой привязки к FX.
- Добавлены unit-тесты расширенного каталога моделей.

## Ограничения
- Сохранение applicationId намеренное для совместимости обновления; это не официальное приложение NIU.
- Сервисные напоминания и отметки вводятся владельцем вручную. Нет подтверждённого считывания одометра/состояния батареи для всех моделей.
- Новые варианты каталога — распознаваемые названия, а не заявление о подтверждённой BLE/ECU совместимости.
- NIU Cloud остаётся reverse-engineered совместимостью; нужен реальный тест на аккаунте/регионе.
- Полная Android/Compose сборка и APK в этой среде не подтверждены: отсутствуют Gradle и Android SDK.
