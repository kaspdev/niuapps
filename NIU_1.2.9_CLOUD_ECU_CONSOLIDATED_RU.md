# NIU Mobility Studio 1.2.9 — Cloud ↔ ECU consolidated update

## Что включено
- Сохранён существующий NIU Cloud OAuth flow и зашифрованное хранение токена.
- Сохранён `motoinfo/list`; синхронизация продолжает обновлять локальные карточки по SN.
- В карточку «NIU CLOUD ↔ ECU» добавлена сводка ECU Engine: результат сопоставления, определённое семейство, согласованность Cloud/BLE и состояние BLE-соединения.
- Добавлен независимый SDK-модуль `com.niu.sdk.bridge.CloudEcuBridge` для строгой корреляции Cloud/BLE по точному SN, либо VIN, когда оба SN отсутствуют.
- Добавлена модель состояний ECU-операций. GATT write success классифицируется только как `WAITING_FOR_ECU`, не как выполнение команды.
- Добавлены unit-тесты сопоставления идентификаторов и классификации ответа.
- Существующий реестр команд остаётся fail-closed: неподтверждённые payload не становятся исполняемыми.

## Ограничения
- В текущих BLE-данных не доказано получение SN/VIN из контроллера. Поэтому имя `NIU Link` и факт соединения не считаются идентификацией скутера.
- Cloud match доказывает совпадение записи аккаунта, но не совместимость BLE-протокола.
- `ecuProtocolReady` намеренно всегда `false` до появления проверенной спецификации exact-model/firmware и ACK.
- Не добавлялись неизвестные команды, криптографические обходы, spoofing официального приложения, OTA или factory reset.
- Android build/tests не запускались: Gradle и Gradle Wrapper в среде отсутствуют. ZIP проверен на целостность.
