# NIU Mobility Studio 1.0.6 — Unified Diagnostics & Universal Branding

## Изменения
- Новое общее название NIU Mobility Studio вместо NIU FX Studio.
- Android launcher label и имя Gradle-проекта обновлены; applicationId и namespace сохранены для совместимости обновления с установленной версией.
- Журнал событий стал структурированным и файловым: JSONL, уровни INFO/WARN/ERROR, категории APP/NIU_CLOUD/BLE/NFC/WORKSPACE/MEDIA/VEHICLE.
- Добавлена ротация четырёх файлов журнала примерно по 2 MiB каждый.
- Восстановление событий при запуске; импорт старого журнала SharedPreferences при отсутствии нового формата.
- Экспорт JSON/CSV с отдельными полями времени, уровня, категории и сообщения.
- Секреты редактируются до записи.

## Совместимость и ограничения
`applicationId` и Kotlin namespace оставлены прежними, чтобы не ломать установку поверх 1.0.5 и доступ к существующим данным. Переименование отображаемого продукта не означает официальную аффилированность с NIU.

Полная сборка APK и тест на физическом скутере в текущей среде не выполнялись. NIU Cloud API — исследовательская неофициальная интеграция. Неизвестные BLE-команды не отправляются.
