# NIU Mobility Studio 1.3.0 — управление паролем Secure Tools

- В защищённом меню добавлена кнопка «ПАРОЛЬ».
- Диалог смены пароля запрашивает текущий пароль, новый пароль и подтверждение.
- Новый пароль принимается при длине от 8 символов.
- Новый случайный salt и PBKDF2-HMAC-SHA256 hash сохраняются локально; исходный пароль не сохраняется.
- Проверка входа использует сохранённые credentials, а не только встроенный bootstrap-хеш.
- Предыдущие функции APK export и защиты приложения сохранены.

Версия: `1.3.0` / `versionCode 130`.

Android-компиляция не выполнялась в этой среде.
