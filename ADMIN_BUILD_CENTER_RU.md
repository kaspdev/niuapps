# Единое приложение NIU Mobility Studio

Административная консоль встроена в Full-сборку NIU Mobility Studio и открывается из раздела GitHub Build Center. Отдельный Admin APK больше не собирается и не устанавливается.

- Full APK: основное приложение + административная консоль + защищённые инструменты.
- User APK: основное приложение без административной консоли; защищённые инструменты доступны только при действительном подписанном разрешении.
- GitHub Actions используется для удалённой компиляции и получения артефактов.

Для административной консоли откройте в Full APK раздел Build Center и нажмите «АДМИНИСТРИРОВАНИЕ · КЛЮЧИ · ДОСТУПЫ».
