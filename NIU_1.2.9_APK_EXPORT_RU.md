# NIU Mobility Studio 1.2.9 — экспорт APK

В Build Center добавлена кнопка «ЭКСПОРТИРОВАТЬ / ПЕРЕДАТЬ УСТАНОВЛЕННЫЙ APK».

- Приложение копирует установленный `ApplicationInfo.sourceDir` в приватный каталог `files/builds/`.
- Передача выполняется через Android Sharesheet (`ACTION_SEND`) и `FileProvider` с временным read-grant.
- Исходный APK не изменяется; подпись остаётся подписью установленной сборки.
- Версия приложения не меняется: `versionName=1.2.9`, `versionCode=129`.

Ограничения:
- Это экспорт уже собранного и установленного APK, а не локальная пересборка исходников внутри приложения.
- При split-install `sourceDir` может быть только базовым APK. Для передачи полного универсального артефакта следует использовать APK из GitHub Actions.
- Для установки на другое устройство Android проверит подпись и совместимость. Обновление поверх другой сборки возможно только при совпадающей подписи и корректном versionCode.
