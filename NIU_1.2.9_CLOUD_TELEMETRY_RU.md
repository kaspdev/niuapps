# NIU Mobility Studio 1.2.9 — Cloud Telemetry & Battery

## Изменения
- Сохранён существующий OAuth/session flow и зашифрованное хранение токена.
- Добавлено чтение Cloud telemetry по выбранному SN:
  - `GET /v3/motor_data/index_info?sn=...` — состояние подключения, заряд/состояние батарей, скорость, запас хода, заряд центрального контроллера, GPS/GSM, временная метка.
  - `GET /v3/motor_data/battery_info?sn=...` — данные battery compartments A/B, SOC, температура, циклы, BMS ID и grade.
  - `GET /v3/motor_data/battery_info/health?sn=...` — здоровье батареи и количество возвращённых BMS faults.
  - `POST /motoinfo/overallTally` — общий пробег.
- Каждый endpoint обрабатывается независимо: ошибка одного источника не скрывает остальные.
- В UI добавлена панель Cloud telemetry и ручное обновление.
- Пустые и неизвестные поля показываются как `—`; отсутствующие данные не заменяются нулями.
- Для результата отображаются время получения, состояние источников и предупреждения.
- Данные маркируются как NIU Cloud, а не как live BLE/прямое чтение BMS.

## Ограничения
- Используемые пути и поля описаны в reverse-engineered NIU API и community connector, а не гарантированы NIU как стабильный публичный контракт.
- Доступность зависит от региона, модели, версии сервера и разрешений аккаунта. Конкретный ответ для этого скутера не проверен из среды разработки.
- Температура, SOC, BMS ID, cycles и battery health отображаются только если сервер вернул эти поля.
- Это облачная телеметрия/последнее известное состояние, не гарантированно мгновенные показатели батареи.
- BLE notification values пока остаются raw-first; неизвестный HEX не интерпретируется как напряжение, ток или температура.
- Команды управления ECU не разблокируются этим обновлением.
