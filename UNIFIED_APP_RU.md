# Единое приложение NIU Mobility Studio

В репозитории один Android application module `:app` и одна основная Activity. Отдельного устанавливаемого Admin-приложения/модуля нет. `Full` и `User` — варианты распространения одного исходного Android-приложения, а не два независимых проекта:

- Full APK: IDE, скутеры, диагностика, защищённые инструменты и встроенная административная консоль.
- User APK: та же пользовательская оболочка и обычные функции; административная консоль не включается в пользовательский APK, а защищённые функции доступны только по действительному разрешению, подписанному ключом администратора.
- Администратор создаёт User APK из встроенной консоли. Запрос отправляется в GitHub Actions, где выполняется настоящая Android/Gradle сборка; телефон не запускает Gradle и не компилирует APK локально.
- При ручном запуске workflow из административной консоли собирается только User APK. Обычный запуск workflow из Build Center без параметров сохраняет сборку Full + User; push в `main`/`master` также проверяет оба варианта.
- Android Keystore хранит закрытый ключ администратора на установке Full приложения. Из него экспортируется только открытый ключ; закрытый ключ не включается в APK и не передаётся пользователю.

Для сборки User APK задайте GitHub Actions Variable `NIU_ADMIN_PUBLIC_KEY` значением открытого ключа из консоли администратора. Иначе проверка подписанных разрешений в пользовательской сборке не сможет доверять ключу, и защищённые инструменты останутся закрыты.

Для подписанного Release APK задайте Secrets `NIU_RELEASE_KEYSTORE_BASE64`, `NIU_RELEASE_KEYSTORE_PASSWORD`, `NIU_RELEASE_KEY_ALIAS`, `NIU_RELEASE_KEY_PASSWORD`. Это ключ подписи Android APK, отдельный от ECDSA-ключа разрешений администратора.

Ограничения: GitHub Actions требует репозиторий и разрешение `Actions: Read and write` у Fine-grained token. Без GitHub runner сборка из телефона невозможна. После скачивания Android устанавливает APK только через системное подтверждение. User APK использует `applicationIdSuffix = ".user"` и устанавливается отдельно от Full APK; для обновления уже установленного пользовательского APK нужна та же подпись.
