# NIU Mobility Studio — аудит требований за последние сутки
Дата аудита: 2026-11-07
Репозиторий: https://github.com/kaspdev/niuapps
Проверенная база: ветка main, дерево Git и документы проекта. Это аудит заявленного состояния исходников по документации, а не подтверждение runtime-поведения.

## Итог

В репозитории есть документация и архив `NIU_Mobility_Studio_1.3.2_ONE_APP.zip` (619683 байта), но в корне Git-дерева нет распакованного Android-проекта (`app/`, `niu-sdk/`, `src/`) и нет `.github/workflows/android-build.yml` в проверенном дереве. Поэтому нельзя утверждать, что перечисленные функции реально работают, нельзя исправить Kotlin/UI код и нельзя запустить CI из этого состояния. Документы описывают реализацию 1.3.1/1.3.2, но требуют проверки по исходникам.

## Что реально внесено в Git этим аудитом

- Добавлен этот документ аудита, чтобы зафиксировать различие между заявленным, проверенным и отсутствующим.
- Предыдущая GitHub Issue #1 фиксирует исправления Admin/Keys, pairing, логов, адаптивности и GitHub. Эта issue — список работ, а не доказательство их реализации.

## Блокирующие действия для реальной разработки

1. Восстановить/загрузить в репозиторий распакованный исходный Android-проект из актуального архива (не только ZIP-документацию).
2. Добавить и проверить `.github/workflows/android-build.yml`, Gradle wrapper либо зафиксированную версию Gradle и Android SDK/JDK в CI.
3. Разобрать crash Admin/Keys по stacktrace и добавить regression test.
4. Реализовать QR pairing как отдельный безопасный протокол: одноразовый challenge, подтверждение обеих сторон, обмен публичными ключами, привязка устройства, защищённый канал; отдельно определить способ сетевого соединения и ограничения Android hotspot permissions.
5. Перевести журнал в полноценный экран с lazy list/RecyclerView, корректной прокруткой, фильтрами и сохранением позиции.
6. Провести адаптивный UI проход на узких/широких экранах и длинных локализованных строках.
7. Довести GitHub UI/API: repository browser, public/private create, ветки, tree/file viewer, diff, pull/push, commit, Actions runs/artifacts, permission errors; явно обозначить неподдерживаемые Git операции.
8. Запустить CI, сохранить логи, получить APK Full/User и проверить установку/запуск на Android.
