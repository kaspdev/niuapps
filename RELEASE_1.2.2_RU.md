# NIU Mobility Studio 1.2.2 — NIU Cloud integration & diagnostics

## Что изменено

- Диагностика OAuth v3 и списка транспорта подключена непосредственно к экрану NIU Cloud.
- Для HTTP-запросов добавлены локальные correlation ID и parent trace ID.
- Журнал фиксирует метод, хост, endpoint, имена параметров (без значений), размеры тела/ответа, HTTP-код и длительность.
- В расширенном режиме записываются типы и длины query-параметров, структура JSON, имена ответных заголовков и безопасные значения `Date`, `Server`, `Content-Type`, `Via`, request/trace ID.
- Для HTTPS фиксируется согласованный cipher suite.
- Добавлены цепочки причин исключений и расширенный stack trace.
- В диалоге NIU Cloud появились действия сохранения отдельного Cloud-журнала и перехода к журналу событий с фильтром NIU Cloud.

## Защита данных

Пароль, MD5-дайджест, access/refresh token, cookies, Authorization и значения подписей не записываются. Сырые тела ответов сервера не экспортируются. В диагностике отображаются только структура JSON, безопасные поля и ограниченное описание ошибки.

## Границы проверки

Это интеграция диагностики в приложение, а не подтверждение успешного входа. Алгоритм приватной подписи NIU и полный контракт официального клиента не считаются восстановленными. Для проверки нужен новый лог с устройства после установки этой версии.
