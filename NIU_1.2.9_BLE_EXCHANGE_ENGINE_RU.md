# NIU Mobility Studio 1.2.9 — BLE Exchange Engine

## Изменения без смены версии
- Сохранены `versionName = 1.2.9` и `versionCode = 129`.
- Для каждой ручной BLE-записи создаётся номер обмена `BLE EXCHANGE #N`.
- TX фиксируется только после того, как Android принимает GATT write; журнал содержит UUID, длину и HEX.
- Входящие NOTIFY/INDICATE/READ в течение окна наблюдения фиксируются как `RX_CANDIDATE` с UUID и номером пакета.
- Через 5 секунд без входящего пакета появляется `TIMEOUT`; при получении пакетов закрывается окно RX.
- Отдельно записывается GATT write status. Наличие RX-кандидата не считается подтверждением выполнения команды (ECU ACK).
- Перед ручной записью в `8ec94e32` или `99ea30e2` приложение пытается включить Notify/Indicate на `8ec94e31` (если характеристика присутствует и поддерживает подписку).
- Добавлена кнопка `REPEAT LAST` для повторной отправки последнего пользовательского HEX на его исходный UUID.
- Удалён подробный побайтовый шум из основного журнала; сохраняется полный HEX-пакет.
- Защищённая `8ec94e33` по-прежнему заблокирована.

## Ограничения
- Это универсальный ручной GATT TX/RX инструмент, а не готовые команды LOCK/UNLOCK/FIND/MODE.
- Форматы команд конкретного скутера и firmware не подтверждены; приложение не генерирует неизвестные payload.
- `GATT_SUCCESS` подтверждает только уровень GATT. `RX_CANDIDATE` показывает пакет в окне после TX, но без декодированного протокола не является ECU ACK.
- Проверять только на неподвижном скутере. Не повторять неизвестные пакеты и не отправлять их при движении.
