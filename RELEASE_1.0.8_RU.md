# NIU Mobility Studio 1.0.8 — Telegram & Local API

## Новое

- Раздел **Telegram и локальный сервер** в центре инструментов.
- Сохранение нескольких именованных профилей Telegram-ботов; один профиль работает в Long Polling одновременно.
- Проверка токена через `getMe`, установка `/start`, `/help`, `/status`.
- Allowlist Chat ID обязательна для запуска polling; неизвестные чаты отклоняются. Наличие Webhook проверяется; приложение не удаляет чужую настройку автоматически.
- Команды `/start`, `/help`, `/status`.
- Telegram Bot API `sendMessage` для тестовых и локально инициированных уведомлений.
- Локальный HTTP API с `GET /health` и `POST /notify`, Bearer authentication, настройкой порта и явным loopback/LAN bind.
- Bot token и локальный API key шифруются AES-GCM через Android Keystore; маскирование Telegram bot token добавлено в общий лог-фильтр.
- Документация API и примеры curl.

## Ограничения

- Long Polling и локальный сервер работают в процессе приложения, не являются 24/7 foreground services и могут остановиться при закрытии/выгрузке приложения.
- Webhook не включён: он требует публичного HTTPS endpoint.
- LAN API использует HTTP. Разрешайте LAN bind только в доверенной сети; не пробрасывайте этот порт в интернет.
- Один бот активен одновременно, хотя профилей можно сохранить несколько.
- Нет команд управления скутером через Telegram. Нет заявлений о реальном NIU Cloud push/телеметрии без подтверждённого API.
- Требуется тестирование на устройстве и полная Android build.

## Проверки

Проверяются структура исходников, синтаксис Kotlin, YAML workflow, JSON/XML и целостность ZIP. APK не считается готовым, пока не пройдёт Gradle/Android SDK build и device tests.
