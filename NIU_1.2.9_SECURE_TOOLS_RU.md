# NIU Mobility Studio 1.2.9 — Secure Tools

- Добавлено отдельное меню защищённых инструментов.
- BLE Explorer / nRF, диагностика ECU, журнал событий, обслуживание, Telegram/API и NIU AI Assistant закрыты паролем.
- При первом входе пользователь создаёт пароль (минимум 8 символов).
- Пароль не хранится в открытом виде: используется PBKDF2-HMAC-SHA256 (120 000 итераций, случайная 16-байтовая соль, 256-битный результат).
- Хеш и соль хранятся в приватных SharedPreferences приложения.
- Доступ можно закрыть кнопкой «Заблокировать»; после перезапуска приложения защищённые разделы снова требуют пароль.
- Версия сохранена: versionName 1.2.9, versionCode 129.

## Сборка

Полная Android-сборка в среде изменений не запускалась: Gradle и Gradle Wrapper отсутствуют. После открытия проекта выполните Gradle Sync. Если IDE показывает `Unresolved reference` для `androidx.activity` и `androidx.compose`, сначала проверьте успешную загрузку зависимостей и выбранный модуль `app`, а не удаляйте импорты из исходников.
