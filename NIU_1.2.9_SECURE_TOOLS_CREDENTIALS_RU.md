# NIU Mobility Studio 1.2.9 — пароль и биометрия

- Добавлен заранее выданный пароль защищённого раздела; первичная регистрация пароля больше не показывается.
- Проверка пароля: PBKDF2-HMAC-SHA256, 210 000 итераций, 16-байтовая соль, сравнение через MessageDigest.isEqual.
- После правильного пароля приложение предлагает системную проверку отпечатка. При успехе включает биометрический вход для следующих открытий.
- Биометрия проверяется AndroidX BiometricPrompt; приложение не имеет доступа к шаблонам отпечатков.
- Вход по паролю остаётся резервным способом.
- Версия не менялась: 1.2.9 / 129.

Пароль первичного доступа передан владельцу отдельно. Не публикуйте его вместе с архивом.
