# NIU Mobility Studio 1.3.2 — единая административная сборка

- Административная консоль из Full APK запускает отдельный запрос CI только на пользовательский APK.
- Workflow поддерживает режим `user` и `both`; стандартный Build Center и push в main/master сохраняют сборку обеих конфигураций.
- Добавлена обязательная проверка `NIU_ADMIN_PUBLIC_KEY` для пользовательской сборки: без открытого ключа выданные администратором разрешения не могли бы проверяться.
- Исправлена сериализация workflow-dispatch payload через `JSONObject`, чтобы безопасно передавать имя ветки и выбранную конфигурацию.
- Уточнена архитектурная документация: один Android-проект и один application module; Full/User — варианты распространения, а не отдельные приложения Admin и User.
- Закрытый ключ разрешений остаётся в Android Keystore; в пользовательскую сборку передаётся только открытый ключ.

Проверка Android-компиляции и APK assembly требует Gradle 8.9 и Android SDK 35. В текущем рабочем окружении Gradle wrapper, Gradle и Android SDK отсутствуют, поэтому APK не объявляется собранным.
