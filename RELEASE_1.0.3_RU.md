# NIU Mobility Studio 1.0.3 — Universal NIU

## Обновление
Приложение расширено с FX на линейки NQi, MQi, UQi, GOVA, FX, RQi, FQi и KQi. Добавлен общий каталог моделей и протокольный реестр с доказательностью на уровне точной модели и прошивки.

## Исследования
Добавлены ссылки и анализ NIU App Cloud API, MyNIU ECU reverse engineering и KQi3 Pro hardware research. Облачные API отделены от BLE. Указаны ограничения по ECU поколениям и открытым командам.

## Безопасность
Нет универсальных payload для всех NIU. Неизвестные команды остаются заблокированы; AI не повышает уровень доказательности. UUID FX не используются при выборе других линеек.

## Проверка
Исходный проект обновлён. Для полноценной APK-сборки требуется Android SDK/Gradle toolchain.
