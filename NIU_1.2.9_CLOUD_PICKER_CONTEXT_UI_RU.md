# NIU Mobility Studio 1.2.9 — Cloud Picker & Context UI

## Изменения
- В карточке NIU Cloud добавлено контекстное меню выбора скутера из серверного списка.
- Выбор Cloud-скутера синхронизирует активный SN; при наличии локального профиля активирует его семейство и модель.
- Для локальных профилей действия «выбрать», «подключить BLE», «изменить» и «Bluetooth Pair» перенесены в контекстное меню.
- Длинные сведения об идентификации, VIN, Cloud ↔ ECU, телеметрии и BMS перенесены в отдельные диалоги «Подробнее».
- В основной карточке оставлены краткий статус, SN/модель, пробег, запас хода, скорость и краткий заряд батареи.
- Авторизация Cloud, сетевые запросы и существующие правила блокировки неподтверждённых ECU-команд не менялись.
