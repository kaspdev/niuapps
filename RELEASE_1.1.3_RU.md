# NIU Mobility Studio 1.1.3 — Telegram Console & Background Service

## Изменения

- Telegram Long Polling запускается отдельным Android Foreground Service и продолжает работу при сворачивании Activity. Сервис запускается пользователем из экрана интеграций и отображается постоянным уведомлением.
- Добавлена проверка обязательного списка разрешённых Chat ID до запуска; обновления из других чатов отбрасываются.
- Роли Telegram: администратор, обычный пользователь и гость. В приложении добавлены поля первичного списка администраторов и обычных пользователей; после запуска администраторы могут менять роли командами бота. Команды управления ролями доступны только администраторам: `/users`, `/grantadmin`, `/revokeadmin`, `/grantuser`, `/revokeuser`.
- Консоль бота получила единый компактный формат `время · уровень · категория · событие`, отдельные фильтры, ограниченный буфер и экспорт. Убраны посторонние записи Local API и импортированные legacy-строки из консоли Telegram.
- `/logs` и `/errors` показывают только события Telegram в кратком читаемом формате; `/help` сгруппирован по разделам.
- Добавлены `/role`, команды управления ролями и описания команд Bot API. `/ai`, `/analyze` и `/fix` используют только настроенный HTTPS backend; `/fix` не применяет изменения автоматически.
- Секреты маскируются перед записью в консоль.

## Ограничения

- Работа в фоне зависит от Android, разрешения уведомлений, энергосбережения производителя и доступности сети. Пользовательская принудительная остановка приложения прекращает сервис. Для надёжной работы следует разрешить уведомления и снять ограничения батареи для приложения.
- Android может завершать сервис в отдельных системных сценариях; `START_STICKY` запрашивает восстановление процесса, но не гарантирует непрерывную доступность.
- Полная сборка и проверка на физическом устройстве должны быть выполнены в Android SDK/Gradle окружении.
