# NIU Mobility Studio 1.1.4

## Практический обход несовместимости входа NIU Cloud

- Добавлен резервный способ подключения через токен действующей сессии, полученной пользователем в официальном NIU app.
- Токен проверяется запросом списка транспорта (`motoinfo/list`) до записи в Android Keystore.
- Невалидный/просроченный токен не заменяет ранее сохранённую рабочую сессию.
- Токен скрыт в поле ввода, не выводится в журнал и не передаётся сторонним сервисам.
- Сохранены обычный логин/пароль и выбор региона GLOBAL/CHINA.

## Ограничения

Этот резервный путь не исправляет серверный запрет устаревшего клиента на password-login. Он позволяет использовать сессию, которую NIU уже выдал официальному приложению, если сервер продолжает принимать её для `motoinfo/list`. Формат и срок жизни токена определяет NIU; при отзыве/истечении потребуется получить новую сессию. Приложение не извлекает токен автоматически из другого приложения.

Полная Android-сборка должна быть выполнена в Android SDK/Gradle окружении.
